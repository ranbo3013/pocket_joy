# PocketJoy V3.0 产品设计文档

> 版本：V3.0 | 日期：2026-06-07 | 状态：设计稿

---

## 一、版本定位

**从「工具」到「玩具」——让口袋成为用户愿意花钱打扮的虚拟宠物。**

V2.0 解决了留存问题（闹钟 + 激励），V3.0 回答两个核心问题：
- **钱从哪来**：皮肤商店 + 音效包（订阅 + 买断混合变现）
- **壁垒在哪**：幸运事件 + 口袋情绪 + 周报卡片（竞品抄不走的差异化体验）

**核心原则不变**：全本地，不登录，不联网，首页不展示真实金额。

## 二、个性化装扮系统（变现层）

### 2.1 皮肤商店

所有皮肤为**同名 PNG 替换 + 配置映射**，和现有资产替换架构一致，开发成本低。

| 类别 | 免费 | 付费（买断 ¥） | 付费（订阅） |
|------|------|---------------|-------------|
| 🎒 口袋皮肤 | 1 款默认 | ¥6-18/个 | Plus 订阅免费换 |
| 🪙 金币样式 | 1 款默认 | ¥3-6/个 | Plus 订阅免费换 |
| 🏆 金条外观 | 1 款默认 | ¥6-12/个 | Plus 订阅免费换 |
| 🔊 音效包 | 1 套默认 | ¥6-12/套 | Plus 订阅免费换 |
| 🎨 主题套装 | - | ¥18-30/套 | Plus 订阅免费换 |

**Plus 订阅**：¥12/月 或 ¥98/年，全部皮肤 + 音效包免费使用。

### 2.2 皮肤预览与切换

```
皮肤商店页
  ├─ 分类 Tab（口袋 / 金币 / 金条 / 音效 / 套装）
  ├─ 每个 item：预览图 + 名称 + 价格/订阅标签
  ├─ 点击 → 详情页（大图预览 + 购买/使用按钮）
  └─ 已拥有的标记「使用中」
```

**切换实时生效**：选择皮肤后首页立即更新，无需重启。

### 2.4 口袋命名

- 默认名称「口袋」
- 用户可改名（如「小福袋」「发财包」）
- 通知文案带上名字：「小福袋今天收了 200 金币！」
- 最多 8 个字，emoji 支持

### 2.5 技术要点

- 皮肤资产同名覆盖现有 PNG（无需改代码）
- 皮肤选择状态存 `shared_preferences`
- 音效包映射到 `AudioService` 的播放列表
- 付费验证本地完成（iOS: App Store IAP receipt 本地校验，Android: Play Billing）
- 推荐接入 RevenueCat 处理 IAP 逻辑，比手写省大量时间

## 三、情绪陪伴系统（差异化壁垒）

### 3.1 幸运事件

偶尔掉落「幸运金币」，让用户感觉「今天有好事」。

```
触发概率：约 2-3% 每次掉落（平均每 30-50 次掉一次）

幸运金币特征：
  - 2x 金币价值
  - 金币发出特殊金色光晕（比普通金币大一圈）
  - 特殊音效「叮铃～」（比普通掉落高一个八度）
  - 口袋弹出气泡「🍀 幸运金币 +24！」
  - 触觉：中振动（比普通掉落强）
```

**统计**：成就页新增「幸运星」成就（触发 10 次幸运事件解锁）。

### 3.2 口袋情绪（微表情）

根据工作状态，口袋在图标上方或旁边显示微表情气泡。

| 触发条件 | 表情 | 气泡文字示例 |
|---------|------|-------------|
| 刚上班 | 😊 元气 | 「新的一天！」 |
| 连续工作 2h+ | 😪 打哈欠 | 「有点累了...」 |
| 收到休息提醒 | 🥱 期待 | 「休息一下吧？」 |
| 刚收金币（大额） | 🤩 星星眼 | 「发财了！」 |
| 金条合成 | 🎉 撒花 | 「又一根金条！」 |
| 长时间暂停 | 😴 瞌睡 | 「ZZZ...」 |
| 下班打卡 | 🌙 满足 | 「明天见！」 |

**实现**：
- 微表情为 PNG sprite 或简单的代码动画（emoji + 气泡框）
- 每次状态切换时随机从匹配的表情池中选一个
- 表情显示 3-5 秒后自动消失
- 复用现有 `EmotionTextWidget` 的定位逻辑

### 3.3 周报卡片

每周五自动生成一张精美卡片，可截图分享。

```
┌─────────────────────────────────┐
│                                 │
│          本周工作回顾             │
│         6.1 — 6.7              │
│                                 │
│     ┌───────────────────┐       │
│     │     🪙  2,450     │       │
│     │     金币           │       │
│     │                   │       │
│     │     🏆  2 根金条   │       │
│     │                   │       │
│     │     ⏱️  38h 15m   │       │
│     │     工作时长        │       │
│     └───────────────────┘       │
│                                 │
│   📈 比上周 +12% 金币           │
│   🔥 连续 15 天                │
│   🏆 达成「满勤王」              │
│                                 │
│         ── PocketJoy           │
│         口袋快乐，工作值得        │
│                                 │
└─────────────────────────────────┘
```

**卡片可保存到相册 / 分享到微信等**。这是核心的病毒传播机制——用户自发分享带来自然流量。

**生成时机**：
- 每周五 18:00 自动弹出（可配置关闭）
- 设置页「历史周报」可查看过往所有周报

**实现**：
- 用 `CustomPainter` 或 `RepaintBoundary` + 截图生成 PNG
- 保存到本地相册（`image_gallery_saver` 插件）
- 分享用系统分享 Sheet（`share_plus` 插件）

## 六、变现模型总结

| 收入来源 | 模式 | 预估 ARPU |
|---------|------|-----------|
| Plus 订阅 | ¥12/月 或 ¥98/年 | 主力收入 |
| 皮肤买断 | ¥6-18/个 | 补充收入 |
| 音效包买断 | ¥6-12/套 | 补充收入 |
| 主题套装 | ¥18-30/套（打折组合） | 提高客单价 |

**为什么不全部订阅？**
- 有些用户不想月付，愿意一次性买断一两个皮肤
- 买断选项降低付费心理门槛
- 买断用户看到 Plus 的性价比后可能升级 → 买断是引流品，订阅是利润品

## 七、不做的

- 不做 UGC 皮肤市场（审核成本高）
- 不接入广告（破坏治愈体验）
- 不做 NFT/区块链金币（过度设计）
- 不做社交功能（坚持单人体验）
