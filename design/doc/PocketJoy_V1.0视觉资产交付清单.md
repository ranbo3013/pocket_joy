# PocketJoy V1.0 视觉资产交付清单

**开发版 · 移动端 MVP · 目标：炫酷、治愈、耐看、不刺眼**

> **交付目标**：本清单用于把 PocketJoy V1.0 的视觉想法转成设计与开发都能执行的资产规范。开发可以先接入占位资产，正式视觉到位后按同名文件替换，尽量不改业务代码。

## 2. 风格原则

- 炫酷感来自质感、层次、动效节奏和奖励反馈，而不是高亮度闪屏。
- 首页常驻视觉要安静，触发金币掉落时再短暂增强奖励感。
- 背景以深黑、深灰、暗蓝绿为主，金币和口袋用暖金/红金形成记忆点。
- 避免大面积高饱和紫粉、长时间满屏烟花、高频闪烁和刺眼眩光。
- 文字必须始终清晰，任何光效都不能压住核心数字、按钮或状态提示。
- 资产需要服务"口袋装下快乐"的品牌语义，不要做成单纯赌场、老虎机或理财产品风格。

## 5. 首页动效分镜

| 场景 | 触发条件 | 动效描述 | 时长 | 缓动曲线 | 开发备注 |
|------|----------|----------|------|-----------|----------|
| 首页待机 | 进入首页且已设置工资 | 口袋轻微呼吸，背景柔光缓慢移动 | 循环 4-6 秒 | `ease-in-out`（正弦波式） | 常驻低功耗 |
| 未设置工资 | 首次进入或清除数据后 | 静态大口袋 + 微弱呼吸，不掉金币 | 循环 4-6 秒 | `ease-in-out` | 显示填写工资入口 |
| 金币掉落 | 随机间隔命中 | 金币从上方抛物线落入口袋，金币轻微旋转 | 700-1000ms | `ease-in`（下落加速），进入口袋用 `ease-out` | 路径由代码控制，资产可复用 |
| 口袋接金币 | 金币进入口袋瞬间 | 口袋下沉 2-4px 后回弹，束口轻抖 | 250-400ms | Spring（阻尼 0.6，刚度 200） | 和金币消失同步 |
| 文案反馈 | 金币掉落后 | 文案淡入、停留约 2 秒、淡出 | 约 2600ms | `ease-in-out`（淡入 300ms + 停留 2000ms + 淡出 300ms） | 不要遮挡统计区 |
| 合成金条 | 累计金币达到 1000 的整数倍 | 金条轻微闪光，少量金币粒子环绕 | 800-1200ms | `ease-out`（起快落慢，有仪式感）| 禁止强闪烁 |
| 暂停 | 用户点击暂停或 App 退后台 | 口袋进入安静态，光效降低 | 200-300ms | `ease-out` | 停止计时与金币掉落 |

### 5.1 动效细节补充 **[新增]**

#### 金币掉落路径规格

| 参数 | 值 | 说明 |
|------|-----|------|
| 生成区域 X | 屏幕宽度 20%-80% | 每次随机偏移 ±10% |
| 生成区域 Y | 口袋束口上方 80-180px | 随机高度，避免轨迹过于一致 |
| 目标点 | 口袋束口中心坐标 | 以口袋容器的锚点中心为准 |
| 路径形状 | 贝塞尔曲线（二次） | 控制点随机水平偏移 ±30px，让轨迹更自然 |
| 旋转角速度 | 180-360°/s | 随机方向（顺时针/逆时针各 50% 概率） |
| 缩放 | 1.0 → 0.3 | 进入口袋时缩小消失 |

#### 背景光效移动规格

| 参数 | 值 | 说明 |
|------|-----|------|
| 光效 1（暖金） | `#F0D060`，透明度 8%-15% | 大光斑，直径约屏幕宽度 60% |
| 光效 2（蓝绿） | `#5BC0BE`，透明度 5%-10% | 中等光斑，直径约屏幕宽度 40% |
| 移动方向 | 顺时针缓慢旋转 | 光效 1 周期约 20s，光效 2 周期约 15s（不同速，更有层次） |
| 模糊半径 | 80px 高斯模糊 | 两个光斑均使用 `ImageFilter.blur` |

### 5.2 动画冲突处理规则

| 当前动画 | 新触发 | 处理方式 |
|----------|--------|----------|
| 金币掉落 | 金条合成 | 掉落播完 → 触发合成（排队，不叠加） |
| 金币掉落 | 用户暂停 | 立即中断掉落动画，口袋立即进入 paused 态（用户操作优先） |
| 金条合成 | 金币掉落 | 金条合成优先播完，掉落排队等待 |
| 连续排队 > 2 个 | 新掉落触发 | 丢弃最早排队项，仅保留最近 2 个（防止积压） |
| 任何动画 | 退后台 | 立即暂停，回前台不恢复未完成动画 |

## 7. 音效资产

| 音效 | 文件名 | 触发场景 | 时长/要求 | 格式 |
|------|--------|----------|-----------|------|
| 金币掉落 | `sfx_coin_drop` | 普通金币掉落 | 100-300ms，清脆但不刺耳 | AAC + OGG 双格式 |
| 口袋接住 | `sfx_receive` | 金币进入口袋 | 100-250ms，低音量弹性反馈 | AAC + OGG 双格式 |
| 金条达成 | `sfx_gold_bar` | 累计 1000 金币 | 500-900ms，有奖励感但不夸张 | AAC + OGG 双格式 |
| 轻提示 | `sfx_prompt` | 设置保存、暂停、恢复 | 100-250ms，低存在感 | AAC + OGG 双格式 |

**音效通用要求**：
- 默认音量 35%（应用内音量系数，非系统音量）
- 必须支持全局关闭和仅震动模式
- 所有音效应为短文件，V1.0 不使用循环背景音乐
- 音频规格：采样率 44.1kHz，码率 128kbps，单声道（音效无需立体声）
- 每种音效提供 AAC（`.aac`）和 OGG（`.ogg`）双格式，Flutter 运行时按平台自动选择（iOS 优先 AAC，Android 优先 OGG）

## 8. Rive/Lottie 状态机规格 **[新增]**

### 8.1 大口袋状态机

```
                    ┌─────────┐
         ┌─────────│  idle   │◄────────┐
         │         └────┬────┘         │
         │              │              │
         │       [进入首页+已设工资]     │
         │              │              │
         │              ▼              │
         │         ┌──────────┐        │
         │    ┌───│breathing │───┐    │
         │    │   └──────────┘   │    │
         │    │                  │    │
         │ [金币进入]      [暂停/后台] │
         │    │                  │    │
         │    ▼                  ▼    │
         │ ┌──────────┐   ┌─────────┐ │
         │ │ receive  │   │ paused  │ │
         │ └────┬─────┘   └────┬────┘ │
         │      │              │      │
         │ [弹跳结束]      [恢复]      │
         │      │              │      │
         └──────┴──────────────┘──────┘
```

| 状态 | Rive 输入/Trigger | 说明 |
|------|-------------------|------|
| `idle` | 默认状态（无 trigger） | 静态/微弱呼吸（未设置工资时） |
| `breathing` | `breathing_input`（bool，true 进入 / false 退出） | 慢呼吸循环（4-6s 周期） |
| `receive` | `receive_trigger`（fire 触发） | 口袋下沉→回弹→束口轻抖，播完自动回到 breathing |
| `paused` | `paused_input`（bool，true 进入 / false 退出） | 微暗、动效最低，退出时淡入回 breathing |

> Rive 文件中的实际 input/trigger 名称以上表为准。设计师交付时需确保命名一致。

**金币动画**（Lottie 或代码实现，无需 Rive 状态机）：
- 使用代码控制抛物线和缩放，Lottie 仅提供金币旋转闪烁的循环动画（`coin_spin.json`）
- Lottie 触发：`play()` 开始循环旋转，`stop()` 停止；无复杂状态切换

## 9. 尺寸与性能预算

| 项目 | 建议 |
|------|------|
| 位图尺寸 | 主视觉按 3x 设计，宽度建议 900-1200px；小图标使用 SVG 或按平台规范导出 |
| 透明背景 | 口袋、金币、金条等前景资产必须支持透明背景 |
| 动画体积 | 单个 Lottie/Rive 尽量控制在 500KB 内；首页首屏总资产尽量控制在 2MB 内 |
| 常驻动效 | 只保留慢呼吸和低频光效，不持续大量粒子动画 |
| 闪烁限制 | 不使用高频闪烁；奖励动效单次不超过 1200ms |
| 深色适配 | 所有资产必须在 `#000000`、`#1A1A1A`、暗蓝绿背景上可读可辨 |
| **内存预算** | 运行时总内存 ≤200MB（含 Flutter 引擎开销） |
| **帧率目标** | 中端设备首页动画 ≥30fps；参考设备：Snapdragon 7 Gen1 / iPhone 12 |
| **电池影响** | 前台运行 1 小时耗电 ≤8%；常驻动画 CPU 占用 ≤5%，GPU 占用 ≤15%（iPhone 13 参考值） |

## 10. 响应式适配

| 断点 | 设备类别 | 布局调整 |
|------|----------|----------|
| 320-375px 宽 | 小屏手机（iPhone SE, 旧 Android） | 口袋缩放至 70%，间距收紧为默认的 0.85 倍，金币字号降为 28sp |
| 375-414px 宽 | 标准手机（iPhone 12-16, Pixel） | 默认布局（口袋 100%，所有设计令牌按 §9 默认值） |
| 414-430px 宽 | 大屏手机（iPhone Pro Max） | 口袋缩放至 110%，间距放大为默认的 1.1 倍，统计区字号不放大 |

**适配原则**：
- 主视觉容器按屏幕宽度比例自适应（`MediaQuery.of(context).size.width` 为基准），不使用固定像素
- 文字使用相对单位（sp），保持可读性
- V1.0 **仅支持竖屏**（`portrait`），横屏时锁定竖屏方向，不提供横屏布局

## 11. 占位资产策略

- 开发启动时可以先使用简单矢量口袋、圆形金币和代码渐变背景。
- 所有资源路径、文件名和状态机先按本清单确定，后续正式资产同名替换。
- 动画组件需要支持 idle、receive、paused 等状态，即使占位资产只有静态图，也要先保留状态接口。
- 不要把业务逻辑写死在某个图片尺寸上；主视觉容器按屏幕宽度比例自适应。

| 策略 | 说明 |

## 13. 交付验收标准

| 检查项 | 验收标准 |
|--------|----------|
| 完整性 | P0 资产全部存在，文件名与目录符合清单 |
| 可替换性 | 替换正式资产后不需要修改核心业务逻辑 |
| 视觉一致性 | 口袋、金币、金条属于同一风格体系，不像拼贴素材 |
| 耐看性 | 首页常驻 5 分钟无刺眼、疲劳、强闪或遮挡文字问题 |
| 性能 | 中端 Android 设备首页动效无明显卡顿，退后台停止动画 |
| 隐私 | 资产和截图不包含真实工资、真实金额或货币符号 |
| 无障碍 | 关键按钮图标具备语义标签，颜色对比不影响操作识别 |
| **分辨率** | @1x / @2x / @3x 下口袋和金币清晰无锯齿；位图资产以 @3x 为设计基准（宽度 900-1200px），导出时生成 @1x 和 @2x 降采样版本 |

## 14. 设计交付建议

建议顺序：
1. 先产出**首页视觉定稿**，确认大口袋质感、背景光效、金币风格和文字层级
2. 再产出**大口袋 Rive/Lottie 状态动画**，优先实现 idle 和 receive
3. 最后补齐**金条、图标、音效、启动页和 App 图标**

每轮交付都需要在深色背景和真实手机尺寸上预览，不只看设计画布。
